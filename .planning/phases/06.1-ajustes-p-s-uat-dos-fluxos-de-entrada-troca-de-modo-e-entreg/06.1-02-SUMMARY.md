## Decisions Made

- Kept `FamilyHub` available as a fallback route because existing flows/tests still use it directly, but removed it from the normal authenticated landing path.
- Used route params for active child context rather than a new global/session context because this plan only needs UI navigation state and must not change backend authorization.
- Implemented recent-redemptions focus as local dashboard UI state tied to the real dashboard response, avoiding mock redemptions or a new route.
