<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Navigation state -> mode UI | Route params determine child/responsible mode display. |
| Dashboard API data -> interactive dashboard | Backend dashboard response drives counts and redemptions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06.1-02-01 | Elevation of Privilege | Mode switching | mitigate | Treat mode switching as UI navigation only; do not change JWT, role, or family context. |
| T-06.1-02-02 | Information Disclosure | Route params | mitigate | Do not render token, familyUnitId, accessPin, or accessPinHash; tests assert no leakage where existing patterns support it. |
| T-06.1-02-03 | Tampering | Dashboard counts | mitigate | Keep dashboard sourced from `responsibleService.getDashboard`, never local hardcoded counts. |
</threat_model>
