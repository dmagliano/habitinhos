<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Auth form -> mobile API client | Email/password/family data leaves UI state and enters fetch. |
| Mobile runtime -> SecureStore | JWT persistence depends on remember-session choice. |
| Authenticated session -> navigation | Auth state selects unauthenticated vs authenticated stack. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06.1-01-01 | Information Disclosure | Remember-session storage | mitigate | Store JWT only when `rememberSession` is true; tests assert unchecked login skips `tokenStorage.setToken`. |
| T-06.1-01-02 | Tampering | Register request body | mitigate | Send only backend `RegisterRequest` fields and rely on apiRequest familyUnitId guard. |
| T-06.1-01-03 | Spoofing | Auth errors | mitigate | Preserve backend/auth error handling and do not expose raw token or backend details in UI. |
</threat_model>
