<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| mobile-to-backend | Untrusted mobile input crosses to backend via `/auth/login` and `/me`. |
| secure-storage-to-app-state | JWT persists outside React state and is restored on app start. |
| backend-error-to-ui | Backend technical error body is translated to safe PT-BR copy. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-03 | Spoofing | Bearer token usage | mitigate | Store token through SecureStore wrapper and inject only in Authorization header. |
| T-04-04 | Information disclosure | API errors | mitigate | Keep backend `code/details` out of user UI; expose friendly `userMessage`. |
| T-04-05 | Elevation of privilege | Family context | mitigate | Do not accept or send client-supplied `familyUnitId` for authorization; use `/me` returned context only. |
| T-04-06 | Denial of service | Backend unavailable | mitigate | Represent as recoverable state with retry instead of fake/offline success. |
| T-04-SC | Tampering | `expo-secure-store` install | mitigate | Install package audited as VERIFIED in `04-RESEARCH.md` through `npx expo install`. |
</threat_model>
