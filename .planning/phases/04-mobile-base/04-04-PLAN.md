<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user-input-to-auth-provider | Email/password entered by user is passed to AuthProvider and backend login. |
| auth-state-to-navigation | AuthProvider state determines which navigation branch is visible. |
| family-context-to-ui | Backend-returned family context is displayed without becoming authorization input. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-03 | Spoofing | Login form | mitigate | Submit only through AuthProvider and backend `/auth/login`; no local auth bypass. |
| T-04-04 | Information disclosure | Login/session errors | mitigate | Show user-safe PT-BR messages, never raw backend `code/details`. |
| T-04-05 | Elevation of privilege | FamilyHub mode choice | mitigate | Mode choice changes UI route only; it does not set family authorization truth. |
| T-04-06 | Denial of service | Session restore/network failure | mitigate | Loading and retry states keep flow recoverable without fake success. |
| T-04-07 | Tampering | Logout/session state | mitigate | Logout calls AuthProvider logout and clears token storage from 04-02. |
| T-04-SC | Tampering | Navigation installs | mitigate | Use packages listed as VERIFIED in `04-RESEARCH.md`; install native deps with Expo tooling. |
</threat_model>
