<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Auth restore state -> Register UI | Global auth errors can leak into an unrelated registration flow. |
| Child selector -> Responsible area | A child-facing selector opens responsible management. |
| Responsible home -> Child selector | Responsible area returns to child profile selection. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06.2-01-01 | Information Disclosure | RegisterScreen | mitigate | Do not render session-recovery/auth restore messages on registration. |
| T-06.2-01-02 | Elevation of Privilege | Child selector navigation | accepted | Existing app has no child-auth boundary; responsible access already depends on responsible JWT session. This phase changes navigation only. |
| T-06.2-01-03 | Spoofing | Responsible return action | accepted | Returning to child selector does not alter authentication or active family. |
</threat_model>
