# Phase 06.2: Ajustes pós-UAT de cadastro, seletor de crianças e navegação responsável - Context

**Gathered:** 2026-06-04
**Status:** Ready for planning
**Source:** User post-UAT notes from Expo screenshots and running-app review

## Phase Boundary

This phase is a narrow mobile-only post-UAT adjustment pass. It refines copy and navigation introduced by Phase 06.1 without changing backend contracts, wallet behavior, reward delivery, auth token semantics, or the child/responsible domain model.

## User Findings

### 1. Register screen

- **Reference:** `Screenshot_20260604_194739_Expo Go.jpg` mentioned by user; file was not present under `docs/design/review/` during planning.
- **Problem:** The message `Sua sessão terminou. Entre novamente para continuar.` appears on the account creation screen.
- **Expected:** Registration should show only registration fields/actions and registration-specific errors.
- **Priority:** High

### 2. Children management screen

- **Reference:** `docs/design/review/Screenshot_20260603_114400_Expo Go.jpg`
- **Problem:** Primary button says `Nova criança`.
- **Expected:** Change the action copy to `Cadastrar criança`.
- **Priority:** Medium

### 3. Entry mode selection screen

- **Reference:** `docs/design/review/Screenshot_20260603_114241_Expo Go.jpg`
- **Problem:** `Escolha como quer entrar` adds an unnecessary step between login and app usage.
- **Expected:** Remove this screen from the normal flow. After login, the user enters directly into child mode.
- **Priority:** High

### 4. Child selector screen

- **Reference:** `docs/design/review/Screenshot_20260603_115137_Expo Go.jpg`
- **Problem:** The current flow depends on the intermediate entry-mode screen to access responsible mode.
- **Expected:** On `Quem vai brincar agora?`, add `Gerenciar família` to open the responsible area directly.
- **Priority:** High

### 5. Responsible home screen

- **Reference:** `docs/design/review/Screenshot_20260603_115248_Expo Go.jpg`
- **Problem:** After entering responsible mode, there is no clear action on the home screen to return to the child selector.
- **Expected:** Responsible home shows `Retornar às crianças`, returning to `Quem vai brincar agora?`.
- **Priority:** High

## Current Code Evidence

- `mobile/src/features/auth/RegisterScreen.tsx` renders `useAuth().errorMessage`, so restore/login errors can leak into registration.
- `mobile/src/api/client.ts` and `mobile/src/features/auth/AuthContext.tsx` define the stale-session message without accents as `Sua sessao terminou. Entre novamente para continuar.`
- `mobile/src/features/family/FamilyHubScreen.tsx` still renders `Escolha como quer entrar`.
- `mobile/src/features/child/ChildProfileSelectScreen.tsx` still has `Voltar para família` navigating to `FamilyHub`.
- `mobile/src/features/responsible/ResponsibleChildrenScreen.tsx`, `ResponsibleHomeScreen.tsx`, and child-management tests still contain `Nova criança`.
- `mobile/src/features/responsible/ResponsibleHomeScreen.tsx` navigation type currently does not include `ChildProfileSelect`.

## Locked Decisions

- Registration must filter out stale-session/re-authentication recovery copy. It may still show errors caused by a registration submit attempt.
- The normal flow should not rely on `FamilyHubScreen`. Keeping the component temporarily as dead legacy code is acceptable only if no normal navigation path reaches it.
- `Gerenciar família` on the child selector opens `ResponsibleTabs` without requiring a selected child.
- `Retornar às crianças` on responsible home opens `ChildProfileSelect`, not the active child's tabs.
- No backend changes are in scope.

## Acceptance Summary

- Auth/register copy issue fixed and covered by tests.
- Child creation copy changed to `Cadastrar criança` wherever it is a create-child action visible to the responsible.
- Normal navigation no longer sends users to `FamilyHub`.
- Child selector has direct responsible-management access.
- Responsible home has direct child-selector return.
