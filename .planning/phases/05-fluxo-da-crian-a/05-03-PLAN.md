<interfaces>
Plan 05-01 provides:
- childService.getWallet(token, childId): Promise<WalletResponse>
- childService.listRewards(token): Promise<RewardResponse[]>
- childService.redeemReward(token, rewardId, childId): Promise<RewardRedemptionResponse>
- Reward redemption route is POST /rewards/{id}/redeem with body { childId }.

Reward response fields used here:
- RewardResponse: id, title, description, cost, active, createdAt, updatedAt.
- WalletResponse.balance is the only balance source for affordability and confirmation display.
- ApiError.code === 'INSUFFICIENT_BALANCE' means render `Faltam moedas para essa recompensa.` and refetch wallet.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| reward confirmation -> backend redemption | Client-supplied rewardId/childId and stale balance data cross into a balance-changing backend mutation. |
| backend redemption error -> child UI | Structured backend error codes/messages cross into visible child-facing copy. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Elevation of Privilege | ChildRewardsScreen/childService | mitigate | Redemption body is exactly { childId }; no familyUnitId is sent; apiRequest guard stays in place. |
| T-05-02 | Elevation of Privilege / Information Disclosure | listRewards/redeemReward | mitigate | Mobile lists rewards from backend under responsible JWT and selected child id; backend validates active reward and child family before debit. |
| T-05-04 | Tampering | reward affordability/confirmation | mitigate | UI affordability is explanatory only; confirmation shows balance/cost/remaining balance, backend enforces debit atomically, and INSUFFICIENT_BALANCE is handled after submit. |
| T-05-05 | Information Disclosure | reward screens | mitigate | Do not display token, familyUnitId, walletId internals beyond user-safe balance, coinTransactionId, backend codes, or raw HTTP details. |
| T-05-06 | Information Disclosure | redemption error rendering | mitigate | Semantic branch for ApiError.code `INSUFFICIENT_BALANCE`; generic branch uses UI-SPEC PT-BR copy and hides raw error details. |
</threat_model>
