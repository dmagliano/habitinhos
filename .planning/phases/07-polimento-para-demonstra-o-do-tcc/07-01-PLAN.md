<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local seed config -> persisted demo data | Opt-in seed creates real local database records. |
| Demo credentials -> documentation | Local-only credentials are intentionally documented for demo use. |
| Registration UI -> backend auth API | UI-only confirmation must not become a backend contract. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01-01 | Information Disclosure | DemoDataSeeder | Medium | mitigate | Use only `demo@habitinhos.local`, `Demo12345`, and `1234`; do not include real API keys, production emails, or secrets. |
| T-07-01-02 | Tampering | DemoDataSeeder | High | mitigate | Gate seed behind local profile and explicit `habitinhos.demo.seed.enabled=true`; default false. |
| T-07-01-03 | Repudiation/Data Integrity | Wallet history | High | mitigate | Use wallet service methods for credits/debits so `CoinTransaction` history remains consistent. |
| T-07-01-04 | Elevation of Privilege | RegisterScreen | Low | accepted | Confirmation is UI-only and does not change backend auth/authorization. |
</threat_model>
