<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Unauthenticated login UI -> password reset request | User can submit arbitrary emails. |
| Authenticated child/responsible navigation -> PIN reset | User with active session asks to reset responsible PIN. |
| Responsible area -> account deletion | User initiates destructive account action. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06.3-02-01 | Information Disclosure | Password reset UI | mitigate | Always show enumeration-safe success copy. |
| T-06.3-02-02 | Spoofing | PIN reset UI | mitigate | Require authenticated session and backend password verification. |
| T-06.3-02-03 | Tampering | New PIN form | mitigate | Client validates four digits; backend remains source of truth. |
| T-06.3-02-04 | Repudiation | Account deletion UI | mitigate | Deliberate confirmation, backend logging, session clear on success. |
| T-06.3-02-05 | Elevation of Privilege | Child mode access | mitigate | Deletion action appears only in responsible context. |
</threat_model>
